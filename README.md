# Ishrak Anan — Personal Portfolio

This repository hosts the personal portfolio website of Ishrak Anan on GitHub Pages.

## Current version: v5

The site brings together:
- About and personal journey
- Academic background
- Projects and undergraduate thesis
- Corporate and industrial experience
- Leadership and extracurricular activities
- Awards, scholarships, and recognition
- Skills
- Music and creative interests
- Featured gallery plus an expanded category-based gallery archive
- Contact links and CV

### v5 refinements
- Reliable vertical `More` dropdown in the navigation
- Working Back to Top control
- Thesis portrait added to the Projects & Research section
- Meritorious Student Award added to Awards & Recognition
- Clear replacement images for EngiBiz and the Climate Justice Idea Competition
- Expanded gallery categories for leadership, corporate/industrial exposure, competitions, academic/campus journey, entrepreneurship/events, music, and sports
- User-selected featured images for industrial training, music, Summer Rock Mania, The Boys’ Garage, cricket, and other portfolio areas

The visual system uses a clean, modern-professional layout with restrained Yale Blue and Stormy Teal accents.

## Deployment

The site is intended for GitHub Pages from the `main` branch at the repository root.
